# Juch Guliquey, portfolio

Personal portfolio of Juch Guliquey, AI Engineer and Full-Stack Developer.

Built with Next.js, TypeScript and Tailwind CSS, deployed on Vercel.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Editing content

All copy lives in `src/data/content.ts`: profile, AI highlights, projects, skills, certifications and experience. The resume download is `public/Juch_Guliquey_Resume.pdf`.
